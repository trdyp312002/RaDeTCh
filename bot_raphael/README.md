# 🛡️ บอทราฟาเอล (Raphael) - AI เลขาส่วนตัวอัจฉริยะในชีวิตประจำวัน

ยินดีต้อนรับสู่โปรเจกต์ **บอทราฟาเอล (Raphael)** บอทเลขาฯ ส่วนตัวอัจฉริยะที่ใช้เทคโนโลยี Google Gemini API (โมเดล `gemini-2.5-flash`) ในการดูแลตารางเวลาชีวิตประจำวัน แนะนำโภชนาการ/เมนูอาหาร วินัยในการปฏิบัติงานประจำวัน ทบทวนรูทีน และช่วยเตือนความจำในช่องแชท Discord ด้วยบุคลิกแบบ **พ่อบ้าน/เลขาฯ สุดสุภาพและจงรักภักดี**

## ✨ ความสามารถหลักของราฟาเอล (Core Features)

1. **💬 โต้ตอบนอบน้อมระดับสูงสุด ( butler Chat Mode ):**
   - ตอบสนองคุณท่านผ่านการ Mention หรือพิมพ์ใน DM ส่วนตัว
   - มีเอกลักษณ์พิเศษคือ **จงรักภักดี อบอุ่น และใช้หางเสียง "ครับกระผม/ครับคุณท่าน"** ทุกครั้ง
   - **สมองกลเชื่อมโยงบริบทจริง:** ราฟาเอลจะรับรู้เวลาปัจจุบัน วันหยุด รายการ To-Do ที่ค้างอยู่ และกฎประจำตัว ทำให้เขาสามารถตอบคำถามในชีวิตจริงของท่านได้อย่างชาญฉลาดและตรงจุด!
2. **📝 การจัดการรายการภารกิจอัจฉริยะ (Interactive To-Do List):**
   - บันทึกงานผ่านคำสั่ง `!todo add [ภารกิจ]` (เช่น `!todo add ซื้อผลไม้สด #ส่วนตัว #สูง` จะทำการแยกประเภทและระดับความสำคัญให้อัตโนมัติ!)
   - มีปุ่มโต้ตอบในการ์ดข้อความ (Discord Button UI) ให้คุณท่านกด **[เสร็จสิ้นภารกิจ (Done)]** หรือ **[ลบภารกิจ (Delete)]** ได้โดยไม่ต้องพิมพ์รหัสคำสั่ง!
3. **⏰ แจ้งเตือนความจำพื้นหลัง (Active Reminders Loop):**
   - คำสั่งตั้งเวลาในอนาคต `!remind [นาที] [ข้อความ]` หรือตั้งเวลาแบบเจาะจง `!remind 22:30 [ข้อความ]`
   - มีระบบตรวจวิเคราะห์เบื้องหลังทุกๆ 15 วินาที เมื่อถึงเวลานัดหมาย ราฟาเอลจะมาสั่นกระดิ่งเตือนความจำในห้องแชททันที!
4. **🍳 เมนูแนะนำโภชนาการประจำวัน (Meal Recommendations):**
   - แนะนำรายการอาหารจากฐานข้อมูล `data/menu.json` ด้วยคำสั่ง `!menu` หรือเจาะจงวัตถุดิบ `!menu tag หมู`
   - โชว์ภาพประกอบการ์ด Embed สวยงาม พลังงาน (Calories) ระยะเวลาทำ วัตถุดิบปรุงรส และขั้นตอนประกอบอาหารโดยละเอียด
5. **📅 ผู้ควบคุมรูทีนชีวิตและกฎเกณฑ์ (Routine & Rules Advisor):**
   - สรุปตารางประจำวันตามโหมดชีวิตปัจจุบัน `!routine` (ปกติ) / `!routine ot` (ทำงานล่วงเวลา) / `!routine weekend` (วันหยุด)
   - ทบทวนเป้าหมายการรักษาวินัยผ่านคำสั่ง `!rules`
6. **✈️ แนะนำสถานที่พักผ่อนสุดสัปดาห์ (Travel Spots):**
   - แนะนำจุดท่องเที่ยวเชิงวัฒนธรรม/ธรรมชาติที่น่าสนใจจากระบบ `!travel` เพื่อเสนอทางเลือกพักผ่อนสมองแด่คุณท่าน

## ⚙️ ขั้นตอนการเตรียมตัวและรันระบบ (Setup & Running)

### 1. ติดตั้ง Library ที่จำเป็น
เปิด Terminal ในโฟลเดอร์ `bot_raphael` และทำตามขั้นตอนดังนี้:
```powershell
# สร้างสภาพแวดล้อมจำลอง (Virtual Environment)
python -m venv .venv
.venv\Scripts\activate   # สำหรับ Windows

# ติดตั้งแพ็คเกจ
pip install -r requirements.txt
```

### 2. ตั้งค่าไฟล์ความลับ `.env`
เปิดไฟล์ `bot_raphael/.env` แล้วอัปเดตข้อมูล:
- **DISCORD_BOT_TOKEN:** ใส่ Token ของ Discord Bot ตัวใหม่ที่สร้างขึ้นสำหรับราฟาเอล (ดึงได้จาก [Discord Developer Portal](https://discord.com/developers/applications))
- **GEMINI_API_KEY:** ระบบได้คัดลอกกุญแจสมองกลมาจากโปรเจกต์บอทหลักของคุณท่านให้โดยอัตโนมัติแล้ว!

> ⚠️ **คำแนะนำ:** เพื่อให้สามารถเปิดใช้งานบอทหลัก (BotBas) และบอทเลขาฯ (Raphael) ออนไลน์พร้อมกันได้ แนะนำให้ลงทะเบียนบอทเป็น **คนละตัวกัน** บนหน้าเว็บไซต์ผู้พัฒนาของ Discord ครับกระผม!

### 3. เริ่มรันระบบเลขาฯ
```powershell
python main.py
```
ราฟาเอลจะเริ่มล็อกอินเข้าทำงานใน Discord ทันที และพร้อมต้อนรับคุณท่านตลอด 24 ชั่วโมงครับกระผม! 🛡️💼
